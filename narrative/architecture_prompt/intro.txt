OBJECTIF DE L’APPLICATION
------------------------------------------------------------

Le but de l’application est de prendre une ligne de facture et de déterminer si un ou plusieurs flags s’appliquent à cette ligne.

Une contrainte importante est que de nouveaux flags peuvent être ajoutés régulièrement.

Pour cette raison, l’architecture doit permettre de :

- générer automatiquement du code pour chaque nouveau flag,
- appliquer des règles déterministes lorsque les critères sont objectifs,
- traiter différemment les cas narratifs (texte libre) lorsque l’interprétation est nécessaire.
